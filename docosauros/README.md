# Guía de aprendizaje SHMUELDEV

Sitio de la ruta para formarte como ingeniero de datos y data scientist: fundamentos, backend, modelos, pipelines, nube y frontend.

```bash
npm install
npm start
```

La ruta vive en `docs/`. Cada tecnología tiene su carpeta `GUIA` con el plan completo. La página de inicio está en `src/pages/index.js`.
